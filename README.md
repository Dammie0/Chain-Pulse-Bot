# Chain-Pulse-Bot
AI-powered Binance trading assistant on Telegram built with OpenClaw

# Features
- Live crypto prices for any Binance-listed token
- Technical Analysis (EMA 9/21, Bollinger Bands, RSI)
- Candlestick charts with pattern detection
- Support & Resistance levels
- Swing High/Low identification
- Trade setups with Entry, Stop Loss & Take Profit
- Fundamental Analysis (volume, 24h change, market data)
- Price alerts — notifies you when target is hit
- Open to all Telegram users
- Runs 24/7 on VPS

# Chart Indicators
- Candlestick OHLC data from Binance
- EMA 9 and EMA 21
- Bollinger Bands (20, 2)
- RSI (14) panel
- Support & Resistance lines
- Swing High/Low dashes
- Pattern detection:
  - Double Top/Bottom
  - Head & Shoulders
  - Ascending/Descending Triangle
  - Uptrend/Downtrend (HH/HL, LH/LL)

## Trade Setups
- Bias (Bullish/Bearish)
- Entry Zone
- Stop Loss
- Take Profit 1, 2, 3
- Risk/Reward Ratio

#Tech Stack
- OpenClaw AI Agent Framework

| Command | Description |

| `fa` | Fundamental analysis |

| `setup` | Trade setup with SL/TP |
